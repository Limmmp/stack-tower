# Карточка игры — тексты для консоли

Готово к копированию. Числа в скобках — лимит поля в форме.

---

## Общее

| Поле | Значение |
|---|---|
| Версия | `1.0.0` |
| Архив | `dist/stack-tower.zip` |
| Поддерживаемые платформы | Десктоп, Мобильные (**без ТВ**) |
| Ориентация | Портретная |
| **Игра переведена на** | **только Русский** |
| Возрастной рейтинг | 0+ |
| Игра использует облачные сохранения | **выключено** |
| Отсроченная публикация | выключено |

> **Только русский.** Модерация проверяет поддержку каждого языка из списка.
> Все тексты в игре русские, английской локализации нет — если указать
> английский, игру завернут. Вкладку «Английский» в описании тоже закрыть.

> **Без ТВ.** На телевизоре нет курсора, а кнопки запуска и продолжения
> кликаются только мышью или пальцем — фокуса и навигации пультом в игре нет.
> Модератор не сможет запустить игру с пульта. Добавим ТВ отдельной версией.

> **Облачные сохранения выключены** осознанно: рекорд лежит в `localStorage`,
> Player API мы не подключали. Включать флаг без реализации — обещание,
> которое игра не выполняет.

**Название** (50):

Башня

**Описание для SEO** (160):

```
Ставьте блоки точно друг на друга и стройте башню до небес. Промахнулись — башня сужается. Бесплатная аркада на реакцию, играйте в браузере без установки.
```

**Об игре** (1000):

```
Стройте башню до небес!

Блок едет влево-вправо над вашей башней. Поймайте момент и опустите его точно на предыдущий — тогда башня сохранит ширину. Промахнулись? Нависающая часть отваливается и падает вниз, а площадка становится уже. Ещё пара неточных движений, и ставить будет уже некуда.

Чем выше вы забираетесь, тем быстрее движется блок и тем светлее становится небо: ночь постепенно сменяется рассветом, а звёзды гаснут. Точное попадание подсвечивается вспышкой и не отнимает ни миллиметра ширины.

Управление в один тап, короткие партии на минуту и рекорд, который хочется побить ещё раз. Играйте прямо в браузере — без установки и регистрации.
```

**Короткое описание** (70):

```
Ставьте блоки точно и стройте башню до небес
```

**Как играть** (1000):

```
Нажмите на экран или клавишу пробел, чтобы опустить движущийся блок.

Цель — поставить блок как можно точнее над предыдущим. Часть, которая свисает за край, отрезается и падает вниз, а площадка для следующего блока становится уже.

Если блок лёг почти идеально, он выравнивается автоматически и башня не теряет ширину.

Если промахнуться мимо башни полностью — игра заканчивается. После проигрыша можно один раз продолжить с того же места за просмотр рекламы.

С каждым этажом блок движется быстрее, поэтому чем выше башня, тем точнее нужно рассчитывать момент.
```

**Комментарий разработчика** (2048) — виден модератору, не игрокам:

```
Игра полностью на русском языке, других локализаций нет.
Управление: тап по экрану или клавиша пробел. Ориентация портретная, интерфейс масштабируется под любой размер экрана. Платформа ТВ не заявлена: управление пультом пока не поддерживается.
Монетизация через SDK: полноэкранный блок при перезапуске и rewarded video для продолжения после проигрыша (доступно один раз за партию). Звука в игре нет.
Прогресс (рекорд) хранится локально, облачные сохранения не используются.
```

## Медиа

| Что | Файл | Требование |
|---|---|---|
| Иконка | `promo/icon-512.png` | PNG 512×512, без рамок и скруглений |
| Обложка | `promo/cover-800x470.png` | PNG 800×470 |
| Скриншоты мобильные | `promo/screenshots/*.png` | Мобильные / Портретная, 720×1280 |
| Скриншоты десктопные | `promo/screenshots-desktop/*.png` | Десктопные / Альбомная, 1920×1080 |
| Видео геймплея | пропустить | необязательно |
| Рекламные видео | пропустить | необязательно |

Иконку и обложку **запрещено** делать скриншотами из игры — они собраны
отдельной композицией в `tools/make_promo.py`. Скриншоты, наоборот, обязаны
быть реальными кадрами.

### Скриншоты

Загружать в этом порядке — первый кадр видят чаще всего, и падающий кусок
объясняет механику быстрее любого текста:

1. `falling-piece.png` — отрезанный кусок в полёте
2. `tower.png` — чистая читаемая башня
3. `perfect-flash.png` — вспышка за точное попадание
4. `high-dawn.png` — высокая башня, посветлевшее небо

**Мобильные** — `promo/screenshots/`, файлы без суффикса, 720×1280 (портретная).
**Десктопные** — `promo/screenshots-desktop/`, файлы с `-desktop`, 1920×1080 (альбомная).

Суффикс `-desktop` нужен именно для загрузки: одинаковые имена в двух папках
не различить в диалоге выбора файла, и мобильный кадр уезжает в поле
десктопных — консоль отвечает «Соотношение сторон не 16:9».

Минимум **2 скриншота на каждую платформу**.

Игра портретная, поэтому на широком экране игровое поле занимает полосу
608×1080 по центру, а по бокам виден фон страницы. Это не дефект кадра,
а реальный вид игры на десктопе.

Новые кадры снимать так же (F12 → эмуляция мобильного устройства), класть
в `promo/screenshots/` и прогонять:

```
python tools/normalize_screenshots.py   # -> 720x1280, срезает края канваса
python tools/make_desktop_shots.py      # -> screenshots-desktop/, 1920x1080
```
